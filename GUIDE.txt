EVERYTHING IS POKECRAB - GUIDE RAPIDE (V02.00.00)

1. TESTER SUR TON ORDI
   Ouvre le dossier dans VS Code (gratuit), installe l'extension "Live Server",
   clic droit sur index.html > "Open with Live Server". Le jeu se recharge à chaque sauvegarde.

2. CONTENU DU DOSSIER
   index.html               le jeu complet (un seul fichier)
   sprites/Graphics/        planches de décor : Tilesets, Autotiles, Weather, Fogs
   Les créatures, les icônes et les badges sont dessinés par le jeu : aucune image à fournir.

3. OÙ MODIFIER QUOI (dans index.html, Ctrl+F pour chercher)
   const PC_NAMES=   noms français et anglais des 33 créatures
   const TXT=        tous les textes français et anglais
   const NEWS=       le journal des mises à jour (courrier)
   FB_CONFIG         projet Firebase (connexion, sauvegarde en ligne, avis)
   MP_DB_URL         base de données du multijoueur

4. MULTIJOUEUR
   Le multijoueur utilise la Realtime Database du projet Firebase everything-is-pokecrab
   (région europe-west1). Sans cette base, le jeu affiche « Serveur multijoueur indisponible ».

5. METTRE EN LIGNE
   GitHub Pages : envoie les fichiers avec GitHub Desktop (Commit puis Push origin).
   Le site se met à jour en une à deux minutes.
